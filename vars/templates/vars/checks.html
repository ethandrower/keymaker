A scheduled job on the Keymaker host compares each target's live Dokku config against what Keymaker holds. New on box = keys set directly on the server that aren't in Keymaker yet (candidates to adopt). Dokku-managed = keys Dokku owns (DOKKU_*, GIT_REV, DATABASE_URL…) — shown for visibility and never synced; a change here means the platform reconfigured the app. A stale badge means the check hasn't reported recently — the cron may have stopped.
